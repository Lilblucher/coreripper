FAQ

Questions, answered

Is CoreRipper free?+

Yes. 70+ developer and network tools are completely free, with no signup required. Paid plans only add AI credits, the Workbench and website monitoring.

How do AI credits work?+

Each AI action (a summary, a quiz, a code explanation) uses a small number of credits. Every paid plan includes a monthly allotment that refreshes automatically - heavier tiers simply include more.

Can I use Livia AI for free?+

Yes - Livia AI powers the AI tools at no cost. Premium, Sonnet-5-powered features are available on paid plans when you want the highest quality output.

Do I need an account?+

Not for the free tools - open and use them instantly. You only need an account to save results into the Workbench, set up monitoring, or track AI usage.

Can I monitor my website?+

Yes. Track uptime, SSL, DNS and response time, and get alerted by email or WhatsApp the moment something changes. Monitoring is available on Standard and higher (every plan gets a 3-day trial that includes it).

Is my data private?+

Wherever possible, tools run entirely in your browser - nothing is uploaded. For features that need our servers, data is processed only to return your result and never sold.
